# 💰 Smart Expense Tracker

A desktop-based GUI application built using **Java** and **Swing** following the **MVC (Model-View-Controller) / Repository Pattern**. This application helps users track their daily expenses, manage category-wise budgets, and view overall spending habits through an intuitive user interface.

---

## 🚀 Features

- 📊 **Track Daily Expenses:** Easily record income and daily transactions with amounts and categories.
- 🎯 **Category Budgeting:** Set budget limits for different spending categories and track status.
- 🗄️ **Database Persistence:** Seamlessly stores and manages transaction history using a database backend.
- 💻 **Clean & Modular Codebase:** Project organized into clear layers (`model`, `repository`, `service`, `view`) for scalability and maintainability.
- 🎨 **User-Friendly Interface:** Clean desktop GUI built using Java Swing.

---

## 🛠️ Tech Stack & Architecture

- **Language:** Java
- **GUI Framework:** Java Swing / AWT
- **Database:** JDBC / Database Handler
- **IDE:** IntelliJ IDEA
- **Version Control:** Git & GitHub
- **Architecture Pattern:** Layered Architecture (`App`, `Model`, `Repository`, `Service`, `View`)
